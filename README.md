# Food Ordering System

A console-based **Food Ordering System** developed in **Python** as part of a group project for the **Computer Engineering Practice 2** course. The system enables users to browse the menu, add or remove food items, view their current order, and calculate the total bill through a simple and user-friendly interface.

## Features

- Browse food and drink menu
- Add items to an order
- Remove items from an order
- View current order
- Calculate total bill
- Menu management
- Console-based user interface

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Modular Programming
